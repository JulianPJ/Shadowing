## Checkpoint 1 — source and competitor review

Browser testing blocked: Browser inventory empty; Computer Use stopped because it could not confidently determine Chrome's URL. No page interaction or login has been performed. Web text retrieval of both production URLs returned a tool-level Internal Error; this is not evidence of a site outage.

Source-confirmed findings:

- `src/components/daily-review.tsx`: bare Again/Hard/Good/Easy buttons; one fixed ID list up to 20 cards; grading advances index, with no learning-card requeue or timer; completion says Again returns in 10 minutes; next due computation uses current timestamp but has no dedicated minute tick.
- `src/lib/review-scheduler.ts`: custom `sm2-v1`; Again=10 minutes, first Hard/Good=1 day, first Easy=4 days. User examples 1m/6m/10m/3d are illustrative, not present behavior. Preview intervals must come from the scheduler, not hardcoded copy.
- `src/components/personal-dictionary.tsx`: search is explicitly exact-term; overloaded collection/search/tag/deck/export toolbar; blank deck and filtered-search result falls through to 'No saved vocabulary yet'; all card rows show deck checkboxes; deletion actions lack an undo UI here.
- `src/components/review-entry-actions.tsx`: 'Remove from review' performs suspend; 'Add to review' enrolls in Inbox. Deck membership is separate from review enrollment.
- `src/components/tag-controls.tsx`: tags already support create/rename/delete/apply; explanation exists inside collapsed details. Improve discoverability, do not reimplement tagging.
- `src/components/account.tsx`, `src/lib/sync/client.ts`: auto-sync already starts globally and retries on local write/focus/online/visibility/interval. Account page only represents general learner sync, while review and knowledge have separate channels. Catch-all general sync failures become 'offline'. Avoid claiming manual-only sync.
- `src/components/account.tsx`, `personal-dictionary.tsx`, `word-browser.tsx`, `daily-review.tsx`: small HIBIKI links to home exist, but shared Header does not. Request explicit Back to practice and consistent navigation, not 'no back link exists'.
- `src/components/japanese-text.tsx`: lookup segmentation changes among Intl.Segmenter, readings and morphology depending on furigana and known-word data. Form/lemma selection can vary with display preferences. Canonical phrase selection uses mouseup; touch needs verification.
- `src/components/practice/transcript-panel.tsx`: clicking a transcript row seeks/plays; text uses highlighting but no onLookup. Past styling uses row index, not completed-section evidence.
- `src/components/practice/study-player.tsx`, `src/app/styles/display-preferences.css`: Studio has a separate dark presentation but does not consistently redefine inherited paper/ink tokens for every secondary panel. Source supports user's theme report; exact rendered contrast still requires live testing.
- `src/app/styles/dictionary.css`: meaningful help/field/error text is 8–11px and primary save control is 34px high; verify scale/contrast and touch target usability.
